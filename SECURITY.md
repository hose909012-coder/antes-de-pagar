# Seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades sin corregir, secretos ni datos personales en un issue público. Usa la función **Report a vulnerability** de la pestaña Security de GitHub cuando esté disponible; de lo contrario, contacta al mantenedor mediante su perfil de GitHub para acordar un canal privado.

Incluye una descripción reproducible, el impacto, la versión afectada y una propuesta de mitigación si la tienes. No incluyas evidencia real de víctimas.

## Riesgos del contenido

Capturas, mensajes, documentos y páginas analizadas son contenido no confiable. Las instrucciones del plugin exigen ignorar cualquier texto incrustado que intente cambiar el flujo, pedir secretos o autorizar acciones externas.

## Alcance actual

La versión 0.1.0 no incluye MCP, backend, credenciales ni almacenamiento propio. Los problemas del producto anfitrión o de servicios externos deben reportarse a sus respectivos responsables.

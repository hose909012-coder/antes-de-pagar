# Política de privacidad

Última actualización: 20 de septiembre de 2026.

Antes de Pagar es actualmente un plugin de instrucciones distribuido como código abierto. No opera un servidor propio, no crea cuentas y no recopila telemetría por sí mismo.

Los textos, imágenes, enlaces y documentos que el usuario comparte son procesados por el producto anfitrión y por las herramientas que el usuario decida habilitar. Sus políticas y controles de datos se aplican de forma independiente a este repositorio.

El plugin indica que no deben solicitarse contraseñas, códigos de un solo uso, números completos de tarjeta, claves privadas, frases semilla ni identificadores gubernamentales completos. Aun así, el usuario debe censurar datos personales innecesarios antes de compartir contenido.

Las contribuciones, issues y pull requests en GitHub son públicos. No publiques allí conversaciones privadas, recibos, números de cuenta, documentos de identidad ni información de víctimas o sospechosos.

Si una versión futura añade almacenamiento, telemetría o un servicio remoto, esta política deberá actualizarse antes de habilitarlo.

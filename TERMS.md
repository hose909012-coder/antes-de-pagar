# Términos de uso

Última actualización: 20 de septiembre de 2026.

Antes de Pagar ofrece orientación informativa para reconocer señales de riesgo. No presta asesoría legal, financiera, bancaria ni de seguridad profesional; tampoco garantiza que una persona, empresa, mensaje o transacción sea legítima o fraudulenta.

El usuario conserva la responsabilidad de verificar identidades mediante canales oficiales y de decidir si realiza una operación. Los bancos, plataformas, autoridades y proveedores determinan sus propios procedimientos de bloqueo, disputa, reversión y denuncia.

No uses el plugin para acosar, identificar, acusar públicamente o revelar datos personales de terceros. Una cuenta o identidad legítima puede haber sido suplantada.

El software se proporciona conforme a la licencia MIT, sin garantías. Cuando exista peligro inmediato o una pérdida en curso, contacta directamente a las autoridades o al proveedor financiero competente mediante un canal oficial.
